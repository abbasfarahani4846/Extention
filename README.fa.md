# دستیار هوش مصنوعی کروم 🚀

دستیار هوش مصنوعی کروم (AI Chrome Companion) یک افزونه قدرتمند است که پنل کناری هوش مصنوعی و ترجمه همزمان زیرنویس‌های یوتوب را مستقیماً به مرورگر شما می‌آورد.

این افزونه با پشتیبانی از ارائه‌دهندگان مختلف هوش مصنوعی (مانند OpenRouter، NVIDIA NIM، Gemini و مدل‌های محلی)، تجربه‌ای یکپارچه برای خواندن زیرنویس‌های ترجمه‌شده، چت با مدل‌های هوش مصنوعی و شخصی‌سازی وب فراهم می‌کند.

*برای خواندن به زبان دیگر کلیک کنید: [English](README.md)*

## ✨ ویژگی‌ها

- **💬 پنل کناری چت هوش مصنوعی**: یک پنل کشویی در سمت راست برای چت با مدل‌های هوش مصنوعی محبوب شما در حین وب‌گردی.
- **🌐 پشتیبانی از چندین ارائه‌دهنده**: اتصال به سرویس‌های مختلف:
  - OpenRouter
  - NVIDIA NIM
  - Google Gemini API
  - مدل‌های محلی (مثل Ollama)
- **🎥 مترجم زنده زیرنویس یوتوب**: ترجمه خودکار و بلادرنگ زیرنویس‌های یوتوب با استفاده از هوش مصنوعی برای ترجمه‌های با کیفیت و دقیق.
- **🎨 استودیو شخصی‌سازی وب**: تغییر پوسته‌های رابط کاربری (تاریک/روشن)، استایل زیرنویس‌ها و فونت‌های سفارشی.
- **🌍 رابط کاربری دوزبانه**: پشتیبانی کامل از زبان‌های انگلیسی و فارسی (راست‌چین).
- **🛡️ پشتیبانی از پراکسی**: تنظیمات داخلی پراکسی برای مناطقی که دسترسی محدود به APIهای هوش مصنوعی دارند.
- **🔒 تمرکز بر حریم خصوصی**: کلیدهای API و تاریخچه چت‌ها به صورت محلی در مرورگر شما ذخیره می‌شوند (`chrome.storage.local`).

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js (نسخه 18 یا بالاتر)

### بیلد از سورس
۱. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/your-username/ai-chrome-companion.git
   cd ai-chrome-companion
   ```
۲. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```
۳. افزونه را بیلد کنید:
   ```bash
   npm run build
   ```
۴. افزونه را در کروم بارگذاری کنید:
   - کروم را باز کرده و به `chrome://extensions/` بروید.
   - گزینه **Developer mode** را در گوشه بالا سمت راست فعال کنید.
   - روی **Load unpacked** کلیک کنید.
   - پوشه `dist` که پس از بیلد ایجاد شده است را انتخاب کنید.
